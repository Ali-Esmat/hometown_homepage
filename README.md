# Visit Torshov

A single-page homepage about Torshov, a district in Oslo, Norway. It features a hero banner, three recommended activities, and a local guide card.

Built with HTML and CSS, using Vite as the dev server.

## Run locally

```bash
npm install
npm run dev
```

Then open the URL shown in the terminal (usually http://localhost:5173).

## Build for production

```bash
npm run build
```

## What I practiced

- Semantic HTML (header, main, section, lists, blockquote)
- Flexbox layout without negative margins
- CSS custom properties for the color palette
- Responsive wrapping with flex-wrap and max-width
